# Реле плавного пуску однофазного двигуна 2 кВт (ESP32-C3 MINI)

Фазове керування симістором із байпас-реле, налаштування стартової напруги та часу розгону через веб-інтерфейс. Налаштування зберігаються у NVS (Preferences) і переживають перезавантаження.

## ⚠️ ПОПЕРЕДЖЕННЯ ПРО БЕЗПЕКУ

Пристрій працює зі **смертельно небезпечною напругою 220–230 В**. Усі роботи — лише за відключеного живлення, у корпусі з ізоляцією, з дотриманням норм електробезпеки. З'єднання з комп'ютером (USB) під час підключення до мережі **заборонене** — налагодження проводити через ізольований UART-адаптер або без мережевої частини. Автор не несе відповідальності за пошкодження чи травми.

## Принцип роботи

1. Живлення контролера підключене **в обхід симістора** (безпосередньо від L/N), тому детектор нуля (діодний міст + PC817) формує імпульси на GPIO5 завжди, коли є 220 В (кожні 10 мс при 50 Гц).
2. **Автостарт**: як тільки після подачі живлення з'являються імпульси нуля — автоматично починається плавний пуск. З моменту нуля таймер чекає розраховану затримку й відкриває симістор через оптодрайвер MOC3052 (фазове керування); затримка обчислюється за таблицею (LUT) для дійсного значення RMS — «стартова напруга 40 %» реально означує ~40 % RMS.
3. Рівень плавно росте від `startPct` до 100 % за `rampTime` секунд.
4. Після досягнення 100 % симістор тримає повну напругу ще 0.8 с (захисний інтервал), потім **байпас-реле замикається точно на переході через нуль** (мінімальне обгорання контактів). Симістор при цьому **продовжує відпрацьовувати кожен півперіод паралельно з реле**: опір замкнутих контактів значно менший, тому струм іде через реле, а симістор миттєво приймає струм на себе при розмиканні чи дребеззі контактів.
5. **Зупинка за детектором нуля**: при зникненні імпульсів > 300 мс — послідовне вимкнення: спочатку байпас-реле, після захисного інтервалу (~150 мс) — симістор, перехід у очікування. При появі мережі — автоматичний новий пуск.
6. СТОП з веб-інтерфейсу/кнопки: негайний або плавний (опція «м'яка зупинка» — зворотний рамп на симісторі).
7. Захист: перевантаження за струмом (ACS712, 3 вимірювання поспіль) → аварія з відключенням (скидається лише вручну).
8. **Веб-інтерфейс працює незалежно від наявності сигналу детектора нуля** — налагодження від USB чи іншого джерела живлення (стендовий режим: машина станів і реле проходять повний цикл, симістор без імпульсів нуля природно не тактується).
9. Wi-Fi підключається у фоновому режимі й не затримує пуск двигуна.

## Обладнання (BOM)

| Компонент | Нотатки |
|---|---|
| ESP32-C3 MINI (dev-плата) | напр. ESP32-C3-MINI-1 / Lolin C3 Mini |
| Симістор BTA25-600B / BTA41-600B | радіатор ≥ 10 K/W, ізолювальна прокладка |
| MOC3052 (або MOC3021) | оптодрайвер симістора |
| Rg 360 Ом 0.5 Вт | послідовно з gate (MOC pin6 → Rg → gate) |
| R1 330 Ом 0.25 Вт | LED MOC3052: GPIO4 → R → pin1, pin2 → GND |
| Діодний міст DB107 | детектор нуля |
| R2, R3 47 кОм 2 Вт | послідовно з L і N на вхід моста |
| R4 1 кОм, PC817 | вихід моста → LED PC817 |
| R5 10 кОм | pull-up виходу PC817 до 3.3 В (можна внутрішній) |
| Snubber 39 Ом 2 Вт + 10 нФ X2 | паралельно симістору (для nonsnubberless) |
| Байпас-реле/контактор ≥ 25 А | модуль з оптопарою (in: GPIO6) |
| ACS712-30A (опційно) | у розрив фази, вихід → GPIO1 + RC-фільтр 1 кОм/100 нФ |
| Живлення HLK-PM01 (5 В) + AMS1117-3.3 | ізольований БЖ від мережі |

## Розпіновка ESP32-C3

| GPIO | Призначення |
|---|---|
| 4 | Керування MOC3052 (симістор) |
| 5 | Вхід детектора нуля (RISING, pull-up) |
| 6 | Байпас-реле (активний рівень — конфігурується `RELAY_ACTIVE_HIGH`) |
| 1 | ACS712 OUT (ADC1_CH1), `USE_CURRENT_SENSOR 0` якщо не використовується |
| 9 | Кнопка BOOT = Пуск/Стоп |

GPIO 20/21 (USB) не використовувати.

```
           │                │              │
        [R2 47k 2W]      MT2 ┌──────────┐  │
           │                │ BTA25/41 │  контакти
 N(0) ──┬──┴──[R3 47k 2W]──►│ simistor │◄─ байпас-реле ≥25A ◄── GPIO6 (модуль з опто)
        │                   └────┬─────┘
        │                     MT1└──gate──[Rg 360]── MOC3052 out
        │                                        LED: GPIO4──[R1 330]──pin1; pin2──GND ESP
        │
        └──► (DB107 AC2)   R2 ──► (DB107 AC1)
                 + ──[R4 1k]──►|  PC817 LED |── ─
                 вихід PC817: collector ── GPIO5 (+10k до 3V3), emitter ── GND ESP

 Живлення: L,N ──► HLK-PM01 ── +5V ──► AMS1117 ──► 3V3 ESP32-C3
 ACS712 (опційно): у розрив L до навантаження, OUT ── RC(1k+100nF) ── GPIO1
```

## Веб-інтерфейс

1. Після старту пристрій у фоновому режимі намагається підключитись до збереженої Wi-Fi мережі (до 15 с, пуск двигуна не чекає).
2. Якщо немає — створює точку доступу `SoftStart-XXXX` (пароль `12345678`, captive portal) → http://192.168.4.1
3. У мережі STA доступний за http://softstart.local
4. У картці **Wi-Fi** задаються креденшели домашньої мережі (перезавантаження автоматичне).

Інтерфейс (українською): кнопки ПУСК/СТОП, індикація стану/рівня/струму/потужності/частоти/наявності мережі 220 В; слайдери:

- **Стартова напруга**: 10–80 % (для компресора 2 кВт почніть з 40 %)
- **Час розгону**: 1–60 с (типово 3–7 с)
- **Захист за струмом**: 0–40 А (0 = вимкнено; для 2 кВт ≈ 9 А робочого струму ставте 18–25 А)
- **М'яка зупинка**: плавне зниження напруги при СТОП

## HTTP API

| Метод | Шлях | Опис |
|---|---|---|
| GET | `/api/status` | JSON: state, level, current, freq, mains, up, heap, rssi, ap, ssid, fault |
| GET | `/api/settings` | JSON: startPct, rampTime, softStop, maxCurrent |
| POST | `/api/settings` | form-urlencoded: `startPct`, `rampTime`, `maxCurrent`, `softStop=1/0` |
| POST | `/api/start` | пуск (працює і без мережі — стендовий режим) |
| POST | `/api/stop` | зупинка |
| POST | `/api/wifi` | form-urlencoded: `ssid`, `pass` → перезавантаження |

Стани: 0 Готовий, 1 Розгін, 2 Робота, 3 Гальмування, 4 Аварія, 5 Вимкнення (послідовне відключення реле → симістор).

## Конфігурування (`include/config.h`)

- `PIN_*` — перепризначення GPIO
- `RELAY_ACTIVE_HIGH` — полярність реле (0 для модулів із спрацюванням по «0»)
- `USE_CURRENT_SENSOR` — 0, якщо ACS712 не встановлено
- `CURRENT_MV_PER_A` / `CURRENT_DIVIDER` — калібрування датчика струму
- `AUTO_START_ON_MAINS` — автостарт при появі імпульсів детектора нуля
- `RELAY_ON_DELAY_MS` — витримка на 100 % перед замиканням байпас-реле (800 мс)
- `RELAY_ZC_TIMEOUT_MS` — резервна комутація реле, якщо сигнал нуля зник (100 мс)
- `RELAY_OFF_GUARD_MS` — захисний інтервал між відключенням реле і симістора (50 мс)
- `DEF_*` — заводські значення налаштувань

## Поради

- На холостому ходу двигун може не запускатись при стартовій напрузі < 25 % — підвищуйте, поки ротор надійно починає обертатись.
- Індуктивний характер двигуна зсує реальну криву струму; LUT розрахована для активного навантаження і є добрим наближенням.
- Обов'язково перевірте фазування: детектор нуля та симістор мусять працювати в одній фазі (L — загальна).
- Дуже мала затримка при 100 % (100 мкс) гарантує відкриття симістора практично на початку півперіоду.
